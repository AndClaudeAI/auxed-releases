# Open-source software in auxed

auxed includes the following open-source software. The same list is in the app under **Settings › About › Open-source licences**.

## FFmpeg 7.1 (libavcodec, libavutil)

The auxed codec pack (WebAssembly): decoders for older and unusual formats. Built with GPL parts disabled.

- Licence: GNU LGPL 2.1 or later ([text](licenses/LGPL-2.1.txt))
- Copyright © the FFmpeg developers

## libVLC 3.7.7

The VLC engine, used unmodified (org.videolan.android:libvlc-all).

- Licence: GNU LGPL 2.1 or later ([text](licenses/LGPL-2.1.txt))
- Copyright © VideoLAN and the VLC authors

## AndroidX Media3 (ExoPlayer) 1.9

Google’s ExoPlayer engine and its subtitle rendering.

- Licence: Apache License 2.0 ([text](licenses/Apache-2.0.txt))
- Copyright © The Android Open Source Project

## AndroidX libraries

AppCompat, Core, Core Splash Screen, MediaRouter, CoordinatorLayout, WebKit.

- Licence: Apache License 2.0 ([text](licenses/Apache-2.0.txt))
- Copyright © The Android Open Source Project

## Capacitor 8 and plugins

The app shell: Capacitor core, App, Haptics, Screen Orientation, Splash Screen, Status Bar.

- Licence: MIT ([text](licenses/MIT-Capacitor.txt))
- Copyright © 2017-present Drifty Co.
